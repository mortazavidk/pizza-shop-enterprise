# Pizza Shop Enterprise MIS Challenge
Upload index.html, app.js and leaderboard.html to a GitHub repository root. Enable Settings > Pages > Deploy from a branch > main / root. Open the published URL. No backend required. Learning is unlimited; challenge submissions lock after one attempt and hints cost 10 points. Teams export JSON and instructor imports files on leaderboard.html. Progress is stored in browser localStorage; use a fresh browser profile or clear site data for a new team. Scores are client-side and editable, so use for formative practice, not secure grading. This first version uses selection-based configuration tasks rather than drag-and-drop or live network simulation. Risk scores are illustrative. Leaderboard imports are session-only; retain original files.
