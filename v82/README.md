# Pizza Shop Enterprise MIS Challenge V2
Upload index.html, app.js, leaderboard.html and this README to the root of a GitHub repository. Enable Pages from main / root. Open index.html for students and leaderboard.html for instructors. No backend required. Learning has unlimited attempts; challenge has one scored submission per mission, with 10 points deducted per hint. Drag-and-drop also supports click-to-place. Team registration and submitted scores persist locally; unfinished workspaces reset when switching missions. Export JSON and import into the instructor leaderboard. Scores are self-reported and not tamper-resistant. Network and recovery are educational simulations, not real infrastructure. The network exercise uses the same topology in both modes; other scenarios vary. Risk ratings and costs are illustrative.
