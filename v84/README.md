# Pizza Shop Enterprise MIS Challenge V4
Upload index.html, app.js, leaderboard.html and this README to the root of a GitHub repository. Enable Pages from main / root. Open index.html for students and leaderboard.html for instructors. No backend required. Learning has unlimited attempts; challenge has one scored submission per mission, with 10 points deducted per hint. Drag-and-drop also supports click-to-place. Team registration and submitted scores persist locally; unfinished workspaces reset when switching missions. Export JSON and import into the instructor leaderboard. Scores are self-reported and not tamper-resistant. Network and recovery are educational simulations, not real infrastructure. Challenge scenarios vary across all six missions; the learning interfaces are retained. Risk ratings and costs are illustrative.

Timed challenge: save team, select Challenge Mode, then Start timed challenge. Time runs continuously, including refreshes, and stops after six submissions. Learning is unavailable during the timed run. Export requires completion. Leaderboard ranks by score descending, then elapsed milliseconds ascending. Earlier results are incompatible; V4 starts fresh. Timing is client-side and not tamper-resistant.
